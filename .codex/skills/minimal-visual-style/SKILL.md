# Minimal Visual Style

Inspect `src/tailwind-input.css`, `src/views/home.ts`, `specs/media-aggregation/spec.md`, and `specs/readme-docs/spec.md`. Code is authoritative over `docs/screenshots/home.png`.

## Contract

- Keep the flat off-white canvas, black structural rules, acid signal yellow, and restrained blue and red accents.
- Continue the heavy grotesk headlines, compact monospace metadata, and existing `app-*` tokens.
- Use exposed grid structure, direct labels, and dense but readable information hierarchy.
- Keep source, region, language, time, translation state, and failure state visible.
- Preserve semantic landmarks, keyboard navigation, visible focus, and accessible contrast.
- Avoid rounded cards, gradients, soft shadows, decorative motion, and hidden essential information.

Update screenshots after source behavior and styling are verified; never use a stale screenshot to justify a regression.
