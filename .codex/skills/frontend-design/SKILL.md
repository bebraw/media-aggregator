# Frontend Design

Inspect the existing stack and surrounding UI before choosing a clear visual direction. Build on repository patterns; do not add dependencies, build steps, or a parallel design system without approval.

Favor deliberate typography, spacing, hierarchy, and responsive composition over generic SaaS cards, default styling, or decorative effects without a concept. Keep reusable pieces small, understandable, and easy to prune. Use motion only when it improves comprehension or character.

For changes that should continue the current starter aesthetic, use `minimal-visual-style`. Push toward a stronger brand or showcase direction only when the user requests it.
